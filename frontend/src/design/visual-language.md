# ChainSentinel — Bitcoin Cyber-Forensic Visual Language

This document codifies the design rules, symbolic metaphors, and visual hierarchy of ChainSentinel. The objective is to immediately signal an air-gapped, defense-grade intelligence tool tailored specifically for Bitcoin transaction traffic, mempool broadcasts, and entity topologies.

---

## 1. Core Motifs

### The Chain (Interlocking Blocks & Graph Links)
- **Visual Expression:** Distinct interlocking link segments, rounded rectangular blocks with connector tabs, and chained node headers.
- **Application:**
  - The official mark (`ChainSentinelLogo`): Two interlocking chain link loops forming a defense shield silhouette with a central forensic scan iris.
  - Section dividers, status pills, and loading sequences.
  - Node connection visuals in Link Analysis and Taint Pathfinder.

### The Ledger / Cryptographic Hash
- **Visual Expression:** Monospace 64-character hexadecimal digests, block height counters, and tabular ledger row borders.
- **Application:**
  - Ambient backdrop watermarks (`AnimatedLedgerBackdrop`): Faint, slow-moving upward streams of low-opacity (~2–3%) hexadecimal data.
  - `CopyHash` components with tactile copy verification.
  - Tamper-evident evidence framing with certified SHA-256 seal badges.

### The Network Topology Graph
- **Visual Expression:** Directed nodes, cluster brackets, and animated flow conduits.
- **Application:**
  - Hero animated transaction flow (`MiniTransactionFlow`): Abstract wallet nodes exchanging micro-packets of value.
  - Cytoscape link graph: Shape-encoded entities (hexagons for exchanges, diamonds for mixers, rectangles for transactions, circles for wallets).
  - Ambient background drift behind high-level dashboards.

## 3. Typology Iconography Mapping (NTRO T1–T9)

Each investigative typology generated by `chainsentinel.gen.typologies` maps directly to a custom inline SVG glyph:

1. **`T_ransomware` &rarr; `RansomwareIcon`:** Encrypted block with padlock and exfiltration vectors.
2. **`T_darknet` &rarr; `DarknetMarketIcon`:** Abstract faceted forensic node glyph.
3. **`T_peel_chain` &rarr; `PeelChainIcon`:** Cascading change-address peeling sequence with spend breakout.
4. **`T_coinjoin` &rarr; `CoinJoinIcon`:** Converging multi-party inputs swirling into an obfuscated mixing core.
5. **`T_layering` &rarr; `LayeringIcon`:** Multi-tier nested concentric transaction shells.
6. **`T_structuring` &rarr; `StructuringIcon`:** Fragmented micro-transfers skirting beneath an amber regulatory threshold.
7. **`T_extortion` &rarr; `RansomwareIcon`:** High-urgency targeted transfer anomaly.
8. **`T_dusting` &rarr; `DustingIcon`:** Radiating microscopic satoshi specks unmasking wallet clusters.
9. **`T_multi_cluster` &rarr; `WalletClusterIcon`:** Grouped multi-input addresses locked inside a CIOH cluster bracket.

## 4. Air-Gap & Performance Guarantees

- **No Remote Assets:** 0 CDN links, 0 external font imports, 0 Google Fonts, 0 hotlinked graphics.
- **Motion Reduction:** All ambient backdrops and continuous transitions respect `prefers-reduced-motion: reduce`.
- **Zero Hallucination:** Visuals display actual runtime telemetry or explicit 'N/A' states.
